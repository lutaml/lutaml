= Tutorials

== Overview

This section provides step-by-step learning paths to help you accomplish specific tasks with LutaML. Each tutorial walks you through a complete workflow from start to finish.

== Tutorials

=== link:{site-baseurl}/tutorials/getting-started/[Getting Started with LutaML]

Create a small typed UML model and verify an indexed class lookup.

**What you'll learn:**

* Installing LutaML
* Creating a UML document
* Understanding parser and repository boundaries
* Basic model exploration

---

=== link:{site-baseurl}/tutorials/first-lur-package/[Building Your First LUR Package]

Export a typed UML repository to a LUR package and verify a reload.

**What you'll learn:**

* Exporting a UML repository
* Understanding LUR package structure
* Loading and querying LUR packages
* Preserving source and dependency versions

---

=== link:{site-baseurl}/tutorials/generating-diagrams/[Generating Diagrams]

Render a textual LML model with Graphviz and verify the resulting SVG.

**What you'll learn:**

* Parsing textual LML
* Selecting the output format
* Checking the Graphviz prerequisite
* Exporting diagrams

---

=== link:{site-baseurl}/tutorials/documentation-site/[Creating a Documentation Site]

Generate an HTML model browser, inspect it locally, and understand output modes.

**What you'll learn:**

* Using the Ruby static-site API
* Understanding output modes
* Customizing the site
* Serving and publishing generated output

---

=== link:{site-baseurl}/tutorials/querying-models/[Searching and Querying Models]

Compare exact lookups, structured queries, and grouped text-search results.

**What you'll learn:**

* Full-text search
* Using the query DSL
* Filtering objects by name
* Applying queries to a saved package

== Prerequisites

Most tutorials assume you have:

* Ruby 3.2+ installed
* Basic command-line knowledge
* LutaML installed (see link:{site-baseurl}/core/installation/[Installation Guide])

== Tutorial Format

Each tutorial follows this structure:

1. **Purpose** - What you'll accomplish
2. **Prerequisites** - What you need before starting
3. **Steps** - Detailed walkthrough with code examples
4. **Verification** - How to confirm success
5. **Next Steps** - Where to go from here
