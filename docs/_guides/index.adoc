== Guide Format

Each guide follows this structure:

1. **Purpose** - What this guide helps you accomplish
2. **Prerequisites** - What you need to know or have installed
3. **Concepts** - Key concepts for understanding
4. **Step-by-Step Instructions** - Detailed walkthrough
5. **Examples** - Real-world examples
6. **Troubleshooting** - Common issues and solutions
7. **References** - Related documentation
