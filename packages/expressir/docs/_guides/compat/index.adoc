= Compatibility

Expressir interoperates with established EXPRESS toolchains: it reads
and writes the interchange formats they produce, and its commands map
onto familiar invocations. This section documents the compatibility
surface and its registered divergences.

* *Interchange formats* — the schema.changes comparison report,
  corpus tolerances, and the divergence register
* *Workspace readiness* — `expressir doctor`
